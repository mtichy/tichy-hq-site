# Fetch demo components

Interactive portfolio demo for editorial analytics. **All data is synthetic and illustrative only** — invented people, headlines, and numbers. No backend, API calls, env vars, database, or browser storage.

Routes live under `/builds/fetch/demo`. Case-study framing is at `/builds/fetch`.

## Role-aware copy

Story list notes and plain-language summaries are dual-voice (`author` / `editor`). Author voice (second person) only appears when Viewing as Author **and** the story belongs to the signed-in writer (Dana). Editor view — and any other author's work — always uses third-person publication copy.
